# Changelog

All notable changes to Nono Cleaner will be documented in this file.

## [0.1.0-beta] - Unreleased

### Added

- Native macOS application built with Swift and SwiftUI
- Safe, Review, and Protected safety classification
- Trash-only cleanup with explicit user confirmation
- Source and origin explanations
- High, Medium, and Unknown source confidence
- Large-file discovery
- Time-based organization
- In-app normal and full debug scan reports
- Sorting by name, modification date, size, and risk
- Grouping of explicitly allowlisted low-risk sources
- Running-application guard
- Recent-file modification guard
- Safe handling and reporting of macOS-protected paths

### Safety Notes

- No automatic deletion
- Protected work files are excluded from one-click cleanup
- Unknown cache locations require review unless explicitly allowlisted
- Low-risk cleanup may still cause cache rebuilding or future downloads

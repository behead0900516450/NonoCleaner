# Nono Cleaner v0.1.0-beta

This is the first public beta of Nono Cleaner, a native macOS utility focused on explainable, conservative file cleanup.

## Highlights

- Explainable cleanup with source and purpose descriptions
- Low Risk, Review, and Protected safety model
- Trash-only deletion with explicit user confirmation
- Source explanations and confidence indicators
- Large-file discovery
- Time-based organization
- Normal and full debug scan reports
- Running-app and recent-modification guards
- Awareness of macOS protected paths

## Beta Warning

This is a beta release.

Review items marked **Review** before deleting. **Protected** items cannot be deleted through Nono Cleaner. Low Risk items may still need to be regenerated or downloaded again after removal.

## Platform

- Apple Silicon
- macOS 13 Ventura or later

Intel Macs have not been validated for this beta.

## Privacy

Scanning is local. Nono Cleaner has no telemetry, file uploads, account requirement, or server component. Scan reports may contain local paths and filenames; review them before sharing or exporting.

## Artifact Status

Release artifacts must not be published until Developer ID signing, Apple notarization, Gatekeeper assessment, and clean-environment validation all pass.
